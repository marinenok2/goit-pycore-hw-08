# Домашнє завдання 08 — консольна адресна книга

Бот об'єднує класи адресної книги, роботу з днями народження та збереження даних через `pickle`. Зовнішні бібліотеки не потрібні (Python 3.10+).

## Запуск

```sh
python main.py
```

| Команда | Дія |
| --- | --- |
| `hello` | Привітання |
| `add <name> <phone>` | Створити контакт або додати телефон до наявного |
| `change <name> <old_phone> <new_phone>` | Замінити телефон |
| `phone <name>` | Показати телефони |
| `all` | Показати всі контакти |
| `add-birthday <name> DD.MM.YYYY` | Додати або замінити день народження |
| `show-birthday <name>` | Показати день народження |
| `birthdays` | Показати дати привітань на найближчі 7 днів |
| `close` / `exit` | Зберегти дані та завершити роботу |

Ім'я вводиться одним словом і враховує регістр. Телефон має містити рівно 10 цифр. Дата перевіряється на формат і календарну коректність.

Інтервал днів народження включає сьогодні та наступні 6 днів. Привітання у суботу й неділю переносяться на понеділок, навіть якщо він поза цим інтервалом. Для народжених 29 лютого в невисокосні роки використовується 28 лютого.

Адресна книга автоматично завантажується з `addressbook.pkl` у поточній папці та зберігається при `exit`, `close`, EOF або Ctrl+C. Запускайте програму з папки проєкту, щоб щоразу використовувати той самий файл. Якщо файла ще немає, створюється порожня книга. Якщо файл пошкоджений, програма повідомляє про помилку і завершується, не перезаписуючи його. Завантажуйте лише власні довірені pickle-файли.

## Як побудовано програму

- `address_book.py` — класи `Field`, `Name`, `Phone`, `Birthday`, `Record` та `AddressBook`.
- `handlers.py` — функції для команд і декоратор `input_error`, який повертає повідомлення про помилки введення.
- `storage.py` — функції `save_data` та `load_data` з використанням `pickle`.
- `main.py` — введення команд і головний цикл із перевірками `if` / `elif`.

У контакту може бути декілька телефонів та один день народження. Метод `get_upcoming_birthdays` перевіряє дати й повертає список словників із ключами `name` та `birthday`. Блок `finally` у головній функції викликає збереження перед завершенням роботи.
