Проєкт створено на основі попередньої адресної книги. Додано UML-діаграми, абстрактний клас подання та консольний інтерфейс. Зовнішні бібліотеки не потрібні (Python 3.10+).

Робота для здачі: https://github.com/marinenok2/goit-pycore-hw-08/tree/homework-01

## UML-діаграми

- [Класи адресної книги](diagrams/classes.svg) — поля, контакт, книга та їхні зв'язки.
- [Класи подання](diagrams/views.svg) — абстрактний UserView і конкретний ConsoleView.
- [Редагований файл draw.io](diagrams/assistant.drawio) — обидві діаграми на окремих сторінках. Його можна відкрити в draw.io через «Відкрити з пристрою».

Порожній трикутник позначає успадкування. Зафарбований ромб — складові контакту, порожній ромб — зібрані у книзі контакти. Пунктирна стрілка показує використання іншого класу. `0..1` означає необов'язкове поле, `0..*` — довільну кількість. `main` на другій схемі позначено як функцію, а не клас.

## Що змінилося в коді

У `views.py` описано `UserView(ABC)`. Методи з `@abstractmethod` задають, що має вміти кожне подання: читати команду, показувати повідомлення, контакти, телефони, привітання й довідку.

`ConsoleView(UserView)` реалізує ці методи через `input` і `print`. Контакти показуються картками, команда `help` виводить довідку. Обробники повертають контакти та списки даних, а подання визначає їхній вигляд.

`main(view=None)` приймає об'єкт подання. Якщо нічого не передати, створюється `ConsoleView`. Щоб додати інше подання, потрібно успадкувати `UserView`, реалізувати всі його методи й передати об'єкт у `main`. Перевірки телефонів, роботу з контактами та збереження переписувати не потрібно. Для інтерфейсу з кнопками замість команд може також знадобитися інший цикл керування.

Аналогія: `UserView` — список обов'язків працівника, `ConsoleView` — працівник, який виконує їх у консолі. Адресна книга зберігає дані незалежно від того, хто їх показує.

## Запуск

```sh
python main.py
```

| Команда | Дія |
| --- | --- |
| `hello` | Привітання |
| `help` | Показати всі доступні команди |
| `add <name> <phone>` | Створити контакт або додати телефон до наявного |
| `change <name> <old_phone> <new_phone>` | Замінити телефон |
| `phone <name>` | Показати телефони |
| `all` | Показати всі контакти |
| `add-birthday <name> DD.MM.YYYY` | Додати або замінити день народження |
| `show-birthday <name>` | Показати день народження |
| `birthdays` | Показати дати привітань на найближчі 7 днів |
| `close` / `exit` | Зберегти дані та завершити роботу |

Ім'я вводиться одним словом і враховує регістр. Телефон має містити рівно 10 цифр. Дата перевіряється на формат і календарну коректність.

Інтервал днів народження включає сьогодні та наступні 6 днів. Привітання у суботу й неділю переносяться на понеділок, навіть якщо він поза цим інтервалом. Для народжених 29 лютого в невисокосні роки використовується 28 лютого.

Адресна книга автоматично завантажується з `addressbook.pkl` у поточній папці та зберігається при `exit`, `close`, EOF або Ctrl+C. Запускайте програму з папки проєкту, щоб щоразу використовувати той самий файл. Якщо файла ще немає, створюється порожня книга. Якщо файл пошкоджений, програма повідомляє про помилку і завершується, не перезаписуючи його. Завантажуйте лише власні довірені pickle-файли.

## Як побудовано програму

- `address_book.py` — класи `Field`, `Name`, `Phone`, `Birthday`, `Record` та `AddressBook`.
- `handlers.py` — функції для команд і декоратор `input_error`, який повертає повідомлення про помилки введення.
- `storage.py` — функції `save_data` та `load_data` з використанням `pickle`.
- `views.py` — абстрактний клас подання та консольна реалізація; введення й виведення.
- `main.py` — введення команд і головний цикл із перевірками `if` / `elif`.

У контакту може бути декілька телефонів та один день народження. Метод `get_upcoming_birthdays` перевіряє дати й повертає список словників із ключами `name` та `birthday`. Блок `finally` у головній функції викликає збереження перед завершенням роботи.

## Коротка перевірка вручну

Запустіть `python main.py` та введіть по черзі:

```text
help
add Ivan 0501234567
add-birthday Ivan 10.11.2000
all
phone Ivan
show-birthday Ivan
birthdays
exit
```

Після повторного запуску команда `all` має показати збережений контакт. `add Petro 123` має повідомити про неправильний телефон, а бот — продовжити роботу.
